# Bùi Thanh Vương — Quiet Luxury Backend Developer Portfolio

Trang Portfolio cá nhân cao cấp được thiết kế theo phong cách **Quiet Luxury & Digital System Architecture** dành riêng cho **Bùi Thanh Vương — Backend Developer (PHP/Laravel & Java/Spring Boot)**.

---

## Cấu trúc Mã nguồn (Project Structure)

- **`index.html`**: Trang chính hoàn chỉnh (Zero-Build, mở trực tiếp trên trình duyệt hoặc qua Live Server), tích hợp đầy đủ Three.js WebGL 3D, GSAP ScrollTrigger và 3D Tilt Cards 60fps.
- **`css/styles.css`**: Hệ thống Design Tokens phong cách Quiet Luxury (Obsidian `#09090B`, Charcoal `#0F1015`, Champagne Gold `#C9A96E`, Warm Ivory `#F4F1EA`), hiệu ứng Specular Glare 3D, con trỏ từ tính hai vòng (Dual-Ring Luxury Cursor) và giao diện Blueprint Modal.
- **`js/data.js`**: Dữ liệu cấu trúc đầy đủ về thông tin cá nhân, 4 trụ cột kỹ năng (Skills), lộ trình thăng tiến tại **TCOM (02/2025 - 08/2025)** và bản vẽ kiến trúc (Database Schema, SQL Benchmark, Code Snippet) của 3 dự án.
- **`js/three-scene.js`**: Khối kiến trúc dữ liệu 3D tương tác viết bằng **Three.js WebGL** ở tốc độ 60fps, hỗ trợ chuyển đổi 3 chế độ Topology (`01 / Schema`, `02 / Service-Repo`, `03 / @Transactional`) và phản hồi theo tọa độ chuột.
- **`js/app.js`**: Bộ điều khiển 3D Tilt Physics 60fps, GSAP ScrollTrigger Animations, trình mô phỏng tối ưu truy vấn SQL (`-30% thời gian`), bộ lọc dự án và cửa sổ xem chi tiết kiến trúc (Blueprint Inspector Modal).
- **`src/PortfolioBuiThanhVuong.jsx`**: Phiên bản Component **React + Framer Motion + Three.js** dành cho dự án Vite / Next.js.

---

## Cách khởi chạy nhanh

1. **Chạy trực tiếp ngay lập tức (Không cần cài đặt)**:
   - Mở trực tiếp file `d:\portfolio\index.html` bằng trình duyệt (Chrome, Edge, Safari, Firefox), hoặc sử dụng **VS Code Live Server**.
2. **Chạy qua Local HTTP Server (Tùy chọn)**:
   ```bash
   npx serve .
   ```
